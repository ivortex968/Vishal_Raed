Before We Start — Read This! 👋

Welcome to Gesture Tech! You'll use a tiny motion sensor called the MPU6050 attached to an ESP32 microcontroller to build 3 real projects. Never done this before? No worries — every single step is explained clearly.

🤖 What is the ESP32?

Think of it as a tiny computer you can program. It runs your code and communicates with the sensor and your laptop over USB.

👁️ What is the MPU6050?

It's the motion-sensing brain of your project. It detects movement, tilt, and vibration in 3 directions at once.

🔄 What is an IMU Sensor?

IMU stands for Inertial Measurement Unit. It simply means a sensor that measures motion. The MPU6050 measures three things:

  • Acceleration — how fast something is speeding up or slowing down
  • Rotation — how much it's tilting or spinning
  • Angles — the exact tilt in 3 directions: Roll, Pitch, and Yaw

✈️ Roll, Pitch & Yaw — Simply Explained

Step 2

Wiring the MPU6050 🔌

The wiring is identical for all 3 projects. Only 4 wires — you've got this!

🚨
CRITICAL: Use 3.3V — NOT 5V!

The MPU6050 runs at 3.3V. Connecting it to the 5V pin will permanently damage the sensor. Double-check this before powering on every single time!

💡
Beginner Tips

Match the labels on the MPU6050 (VCC, GND, SCL, SDA) to the labels on the ESP32 (3V3, GND, GPIO22, GPIO21). After connecting, give each wire a gentle tug — it should not come loose. If values are stuck at 0, try swapping SCL and SDA!

PROJECT 01 / 03
✋ 3D Hand Tracking
The MPU6050 reads your hand's tilt and sends angles to your laptop. A Processing sketch draws a 3D hand that follows every move!

1 Install Processing IDE

  • Use the Download button in the Software section above to get Processing.
  • Run the installer. Processing is a separate program from Arduino IDE.
  • Open Processing to confirm it launches correctly.

2 Upload ESP32 Code

Open Arduino IDE → File → New → delete everything → paste this code:

Arduino · Project 1 Code 
#include <Wire.h>
#include <MPU6050_light.h>

MPU6050 mpu(Wire);
float roll, pitch, yaw;

void setup() {
  Serial.begin(115200); // Start serial communication
  Wire.begin();           // Start I2C communication
  mpu.begin();           // Initialize the MPU6050
  mpu.calcOffsets();     // Calibrate: keep sensor STILL during this!
}

void loop() {
  mpu.update();
  roll  = mpu.getAngleX();
  pitch = mpu.getAngleY();
  yaw   = mpu.getAngleZ();

  // Send values over USB as: roll,pitch,yaw
  Serial.print(roll);  Serial.print(',');
  Serial.print(pitch); Serial.print(',');
  Serial.println(yaw); // println adds newline at end

  delay(10); // Wait 10ms before next reading
}

💬 What is Serial.begin(115200)?

This sets the communication speed to 115,200 bits per second. Think of it as a talking speed. Both the sender (ESP32) and receiver (Processing) must use the same number or they won't understand each other!

📤 How to Upload:
  • Connect ESP32 to laptop via USB
  • Tools → Board → esp32 → ESP32 Dev Module
  • Tools → Port → select your COM port
  • Click the Upload button (→ arrow icon). If it fails, hold the BOOT button on the ESP32 while clicking Upload.
  • After upload: Tools → Serial Monitor → set baud rate to 115200 → you should see numbers like 1.23,4.56,7.89 scrolling.

3 Run the Processing Sketch

⚠️
Close Arduino Serial Monitor first!

Only one program can use the serial port at a time. If Serial Monitor is open, Processing cannot connect.

Open Processing → new sketch → paste this code:

Processing · Project 1 Sketch 
import processing.serial.*;
import processing.opengl.*;

Serial myPort;
float roll = 0, pitch = 0, yaw = 0;

// ⬇️ CHANGE THIS to your COM port!
String portName = "COM3";

void setup() {
  size(800, 600, P3D);
  myPort = new Serial(this, portName, 115200);
  myPort.bufferUntil('\n');
}

void draw() {
  background(50);
  lights();
  translate(width/2, height/2, 0);
  rotateY(radians(yaw));
  rotateX(radians(pitch));
  rotateZ(radians(roll));

  fill(255, 220, 180);  // Skin color
  box(80, 100, 30);      // Palm

  pushMatrix(); translate(40,-20,0); rotateZ(radians(30));
  box(25, 60, 25); popMatrix();    // Thumb

  pushMatrix(); translate(-30,-50,0);
  box(20, 70, 20); popMatrix();    // Index finger

  pushMatrix(); translate(0,-55,0);
  box(20, 80, 20); popMatrix();    // Middle finger

  pushMatrix(); translate(30,-50,0);
  box(20, 75, 20); popMatrix();    // Ring finger
}

void serialEvent(Serial myPort) {
  String data = myPort.readStringUntil('\n');
  if (data != null) {
    String[] angles = split(trim(data), ',');
    if (angles.length == 3) {
      roll  = float(angles[0]);
      pitch = float(angles[1]);
      yaw   = float(angles[2]);
    }
  }
}

Find the line String portName = "COM3"; and change COM3 to your actual port (e.g., COM5 or /dev/ttyUSB0 on Mac). This is the most common mistake!

💬 What are these libraries?

pyserial lets Python read data from the USB port (ESP32). keyboard lets Python press and release keyboard keys. Together they make the game controller!

2 Upload ESP32 Code

Arduino · Project 2 Code 
#include <Wire.h>
#include <MPU6050_light.h>

MPU6050 mpu(Wire);
float roll, pitch;

void setup() {
  Serial.begin(115200);
  Wire.begin();
  mpu.begin();
  mpu.calcOffsets(); // Keep sensor still during calibration!
}

void loop() {
  mpu.update();
  roll  = mpu.getAngleX();
  pitch = mpu.getAngleY();

  if      (pitch >  20) Serial.println("UP");
  else if (pitch < -20) Serial.println("DOWN");
  else if (roll  >  20) Serial.println("RIGHT");
  else if (roll  < -20) Serial.println("LEFT");
  else               Serial.println("NONE");

  delay(100); // 100ms between readings
}

3 Run the Python Script

Create a new file called game_controller.py on your Desktop using Notepad and paste this:

Python · game_controller.py 
import serial
import keyboard
import time

# ⬇️ Change this to your COM port!
PORT = "COM3"

KEY_MAP = {
    "UP":    "up",
    "DOWN":  "down",
    "LEFT":  "left",
    "RIGHT": "right",
    "NONE":  None
}

def main():
    ser = serial.Serial(PORT, 115200, timeout=1)
    print("Connected! Start tilting your sensor.")
    current_key = None

    while True:
        line = ser.readline().decode().strip()
        if line in KEY_MAP:
            new_key = KEY_MAP[line]
            if current_key and current_key != new_key:
                keyboard.release(current_key)
            if new_key:
                keyboard.press(new_key)
            current_key = new_key
        else:
            if current_key:
                keyboard.release(current_key)
            current_key = None
        time.sleep(0.05)

main()

  • Open poki.com in your browser → search for Hill Climb Racing
  • Click on the game window to focus it, then tilt your sensor to play! 🎮

PROJECT 03 / 03
🚨 Smart Accident Detector
Detect sudden jerks or impacts! When a strong force is detected, an alert fires in Serial Monitor — just like Apple Watch fall detection or car airbag systems!
🌍
Real World Connection

Apple Watch uses accelerometers for fall detection. Cars use them to trigger airbags. Medical devices detect patient falls. You're building a simplified version of these systems today!

1 Wiring (Same as Before!)

Already wired from Project 1 or 2? You're all set — same 4 connections, no changes needed!

2 How It Works

When sitting still, the sensor only feels gravity (≈ 1.0 G). A sudden jerk spikes this above normal. We use:

Total Acceleration = √(ax² + ay² + az²)

If this exceeds 2.5 G, we declare an accident! You can tune this threshold.

3 Upload the Detection Code

Arduino · Project 3 Code 
#include <Wire.h>
#include <MPU6050_light.h>

MPU6050 mpu(Wire);

// How strong a jerk must be to trigger (2.5 = 2.5x gravity)
float JERK_THRESHOLD = 2.5;

// Wait 3 seconds before detecting another accident
unsigned long lastAlertTime = 0;
unsigned long COOLDOWN_MS   = 3000;

void setup() {
  Serial.begin(115200);
  Wire.begin();
  mpu.begin();
  Serial.println("Calibrating... Keep sensor STILL!");
  mpu.calcOffsets(); // Takes about 3 seconds
  Serial.println("Done! Ready to detect accidents.");
}

void loop() {
  mpu.update();

  float ax = mpu.getAccX();
  float ay = mpu.getAccY();
  float az = mpu.getAccZ();

  float totalAcc = sqrt(ax*ax + ay*ay + az*az);

  Serial.print("Accel: ");
  Serial.println(totalAcc);

  unsigned long now = millis();
  if (totalAcc > JERK_THRESHOLD && (now - lastAlertTime) > COOLDOWN_MS) {
    lastAlertTime = now;
    Serial.println("================================");
    Serial.println("  ACCIDENT DETECTED! ALERT!     ");
    Serial.print ("  Peak Acceleration: ");
    Serial.print (totalAcc);
    Serial.println(" G");
    Serial.println("================================");
  }

  delay(50); // Check 20 times per second
}

💬 What is millis()?

millis() returns how many milliseconds have passed since the ESP32 powered on. We use it to create a cooldown — after one alert, we wait 3 seconds before alerting again. This prevents one jerk from flooding the screen with alerts.

4 Test It!

Upload and open Tools → Serial Monitor (baud rate 115200). Try these:

  • Hold still — value reads ≈ 1.0 G
  • Tilt slowly — value stays near 1.0 G
  • Quick sharp flick — value spikes and ACCIDENT DETECTED! appears! 🚨
🎛️
Adjusting Sensitivity

Triggers too easily? Increase JERK_THRESHOLD to 3.0 or 4.0. Not detecting jerks? Lower it to 2.0. Experiment and find the sweet spot!
